## Option 1: Short & Professional (English)

**Subject:** Questions Bank – Default View Overview & Recent Updates

Hi,

Please find below a brief overview of the **Questions Bank** default view and the updates we have made.

### Default view – what you see

- **Header:** Total Questions, Total Marks, and Pending Verification counts (badges).
- **Actions:** Verify Questions (with pending count), Import Questions, Add Question.
- **Filters:** Subject, Chapter, Difficulty, Verification Status (dropdowns auto-submit on change).
- **Quick jump:** Enter Question ID and click “JUMP QID” to go to that question’s edit page.
- **Search:** Enter search term and click “Q Search” to filter questions (Enter key also works).
- **Table:** QID, Question Text, Difficulty, Chapter (editable dropdown), Verification status, Edit/Delete.
- **Verification:** “Verify Questions” opens a modal to Approve/Reject/Skip pending questions one by one.
- **Pagination:** Shows “Showing X to Y of Z entries” when there are multiple pages.

### Recent updates

1. **Search placeholder:** Updated from incomplete “Enter ” to “Enter search term” for clarity.
2. **Search button:** Label set to “Q Search” for consistency with the UI.
3. **Search on Enter:** Pressing Enter in the search box now correctly triggers the search (bug fix).
4. **Form handling:** Search input now has proper `name="key"` so filters and search work correctly together.

If you need any changes or have questions, please let us know.
